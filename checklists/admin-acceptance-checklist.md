# Admin Acceptance Checklist

- [ ] Admin link only appears for authorized roles.
- [ ] Product can be created with category, SKU, retail/wholesale price and cost.
- [ ] Product can publish with 1–10 images; 11th image is blocked.
- [ ] Primary image, ordering and alt text save correctly.
- [ ] Video can upload/link and only publishes when ready.
- [ ] Product list searches name/SKU and sorts columns.
- [ ] Category hierarchy updates storefront dropdown.
- [ ] Inventory shows product, SKU, category, location, on hand, reserved, available, reorder point, cost and value.
- [ ] Receive/adjust/waste actions create movements and audit data.
- [ ] Customer list searches name/company/email/phone.
- [ ] Retail, wholesale and tax-exempt status are independent.
- [ ] Invoice, payment and balance due reconcile.
- [ ] Monthly/yearly sales, COGS, profit, expenses, inventory and amount received reconcile.
- [ ] Excel preview reports row-level errors and commit is idempotent.
